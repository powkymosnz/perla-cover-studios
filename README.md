# LA PERLA Cover Studio

An original offline coastal crime cover maker. Turn local photos and your caption into a bold, multi-panel poster with six layouts, six colour grades, independent crop controls, local ink treatment and editable lettering.

Run `node serve.ts`, then open http://localhost:8080 in desktop Chrome. No install or build step. The browser uses only app/ files; your photos stay on your device.

Export PNGs at **1080×1080**, **1080×1350** or **1920×1080**. Use the supplied AI sample photos or import your own. Click a panel to select, drag to crop, scroll to zoom, or use the panel selector and zoom slider. The focused preview also supports arrow keys.

Package with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`. See STRATEGY.md for the build and verification log and shots.json for the captured screenshot compositions.

MIT application code; local Anton and Kaushan Script fonts ship with their SIL Open Font Licenses. Supplied samples are AI-generated and free to use. This is an original fictional setting, with no official game artwork or branding.
